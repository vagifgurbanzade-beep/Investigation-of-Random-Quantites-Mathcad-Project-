Investigation of Random Quantities – Mathcad

This project focuses on the statistical analysis of experimental electrical voltage measurements using **PTC Mathcad Prime**.

The aim is to investigate random variations in measured data, apply fundamental statistical methods, and evaluate measurement uncertainty.

The project was developed as part of my undergraduate studies in **BSc Science and Technology at the University of Tartu**.


The investigation includes:
- Mean Value: Calculation of the average measured voltage.
- Standard Deviation: Evaluation of data variability.
- Minimum and Maximum: Identification of the measurement range.
- 3-Sigma Analysis: Examination of values outside the three-standard-deviation limits.
- Uncertainty Analysis: Statistical evaluation of measurement uncertainty.

 Tools and Technologies:
- PTC Mathcad Prime
- Statistical Data Analysis
- Mathematical Modeling
- Experimental Data Processing

 Project Files:
- Mathcad Worksheet (.mcdx): Contains the mathematical calculations and analysis.
- CSV Dataset (.csv): Contains experimental measurement data used in the investigation.



1. Download the Mathcad worksheet and its corresponding CSV dataset.
2. Open the `.mcdx` file in PTC Mathcad Prime.
3. Ensure that the dataset is accessible using the file name and path specified in the worksheet.
4. Review the statistical calculations and results.

Note: PTC Mathcad Prime is required to open and interact with the original worksheet.

Through this project, I gained practical experience in applying statistical methods to experimental data, using engineering calculation software, and interpreting measurement variability.
